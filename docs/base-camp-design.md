# 大本营卡牌与防御机制（已实现）

> 代码：`BaseCampSystem`、`BarrierSystem`、`TrapSystem`、`ShelterSystem`、`DefenseCraftSystem`  
> 配置：`deck_defense.json`、`data/invasion/*.json`

---

## 大本营 `base_camp`

| 项 | 说明 |
|----|------|
| 位置 | 开局场地中央，**不可拖动** |
| 耐久 | 30（`base_core.hp`） |
| 怪物目标 | **优先攻击大本营** |
| 贴身伤害 | 每 2 秒 -1（可被掩体减半） |
| 失败 | 耐久 ≤ 0 → 避难所陷落 |
| 胜利 | 撑过 **12 月相** 且本营仍存活 |

### 修复与恢复

| 操作 | 效果 |
|------|------|
| 将 **零件** 叠在本营上 | 消耗 1 张零件，本营 **+2** 耐久 |
| 每月相结束 | 本营自动 **+2**（`moonRegen`） |

顶栏显示：`本营 28/30`

## 防御障碍 `barrier`

| 卡 | 耐久 | 减速 | 说明 |
|----|------|------|------|
| 铁栅栏 | 12 | 50% | slim，挡路并受损 |
| 木板路障 | 6 | 35% | 便宜 |
| 沙袋墙 / 废铁门 | 16 / 14 | 40% | wide |

- 怪物走进障碍区域会 **减速**，并 **持续敲打障碍**（约 0.5 秒 1 点耐久）。
- 耐久归零 → 卡牌销毁，Toast 提示。

### 加固

将 **铁丝网卷** 叠在栅栏/路障上 → 消耗网卷，该障碍 **+4** 耐久。

## 陷阱 `trap_contact`

| 卡 | 伤害 |
|----|------|
| 地刺带 | 3 |

怪物进入地刺范围会受伤（约 1.2 秒冷却），可击杀变异体。

## 掩体 `shelter`

| 卡 | 效果 |
|----|------|
| 铁皮掩体 | 幸存者在掩体上时，本营受击 **减半**；每月相 **2 次** |

## 入侵波次

读取 `data/invasion/waves.json` + `enemies.json`：

- 月相越高，刷怪越快、同屏越多、种类越多。
- 月末最后 12～15 秒可能 **涌动** 额外刷怪。

## 玩家操作速查

1. 本营在中间，别拖走。  
2. 外圈摆 **细长栅栏** + **地刺带**。  
3. 零件拖本营上 = 修。  
4. 掩体上站人 = 减伤。  
5. 撑到月相 12 即胜。
