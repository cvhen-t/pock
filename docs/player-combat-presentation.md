# 入侵 · 攻击 · 防御 — 玩家呈现指南

> 如何把战斗三层讲清楚、看得见、摸得着（手机竖屏 + 叠卡）  
> 系统规则见 [invasion-attack-defense.md](invasion-attack-defense.md)

---

## 1. 呈现原则（三条）

| 原则 | 含义 |
|------|------|
| **场面即教程** | 不用长文案；细长=栅栏、横条=墙、植物=会打的绿牌，一看就懂 |
| **一层信息一处** | 顶栏管「生存资源 + 时间」；场面管「谁在哪、谁在打」；Toast 管「刚发生了什么」 |
| **少数字、多态势** | 玩家看图标/血条/方向，而不是 DPS 公式 |

---

## 2. 屏幕分区（竖屏，比例自适应）

```
┌─────────────────────────────┐
│ [食物][净水][筹码]  威胁 ○○○ │  ← 生存条 + 威胁指示
│ 月相 3          1:24  ⚠涌动   │  ← 时间 + 月末预警
├─────────────────────────────┤
│                             │
│     · 敌人从边缘进入 ←       │  ← 主战场（叠卡区）
│   ║栅栏║  🌿植物   👤幸存者   │     牌形=含义
│                             │
│                             │
├─────────────────────────────┤
│ （可选）下一威胁：辐射鼠 ↑    │  ← 轻提示条，可折叠
└─────────────────────────────┘
```

- **手指可操作区**：中下 70% 高度，HUD 不挡常用叠放区。  
- **敌人入场**：固定从四边 **屏幕外 0.3s 淡入**，带轻微尘土粒子（废土感）。

## 3. 三层分别怎么「让玩家看懂」

### 3.1 入侵（威胁从哪来、有多急）

| 呈现手段 | 说明 |
|----------|------|
| **入场方向** | 刷怪边闪一下暗红 vignette（左/右/上），0.5s 消退 |
| **威胁指示器** | 顶栏右侧 `○○○`：空心=预计容量，实心=当前敌人数（如 ●●○ 2/3） |
| **敌人卡面** | 统一暗红描边 + 轻微脉冲；Boss 加粗框 |
| **目标线（可选）** | 敌人→最近幸存者细虚线，仅当 ≤2 只怪时显示，避免乱 |
| **月末涌动** | 倒计时 &lt;15s 时月相条变琥珀色 + 「涌动」二字闪烁一次 |
| **音效** | 远处嚎叫 → 入场 → 贴身低吼（见音频规范） |

**一句话教玩家**：「红框卡从边上冲过来，会找人。」

### 3.2 防御（挡在外围）

| 牌形 | 玩家应理解成 | 视觉 |
|------|--------------|------|
| **slim** 栅栏/路障 | 竖条防线，挡路 | 细长牌 + 金属/木纹理；**耐久条在牌底** |
| **wide** 沙袋/地刺 | 横条封锁一段路 | 宽牌；地刺带接触时短促火花 |
| **tile** 掩体/污壤 | 占地、站人/种地 | 方牌；掩体上叠人有半透明罩 |

| 反馈 | 时机 |
|------|------|
| 障碍受击 | 牌身闪白 + 耐久条缩短 |
| 障碍毁坏 | 碎屑动画 → 变为 `废墟` 小牌或消失 + Toast「铁栅栏损毁」 |
| 减速生效 | 敌人脚下短暂灰尘拖尾（移速降低） |

**一句话**：「细长竖牌挡前面，宽牌挡一片；条变短说明快坏了。」

### 3.3 攻击（消灭威胁）

| 类型 | 呈现 |
|------|------|
| **攻击植物** | 射程圈 **仅在选中/长按牌时** 显示淡绿圈；开火时牌口小孢子/火花 |
| **武器（叠人）** | 武器图标叠在幸存者**上方**；攻击时幸存者牌短震 |
| **看门犬** | 敌人进范围：犬牌跳向敌、咬击缩放 |
| **陷阱** | 绊索：敌人经过时线绷紧 + 数字飘字 `-4` |
| **击杀** | 敌人牌缩小淡出 + 掉落物 **蹦到旁侧空地**（不挡手） |

**一句话**：「会自己打的植物、拿武器的幸存者、冲上去的狗，都是在帮你清红框怪。」

## 4. 信息优先级（什么时候显示什么）

| 时刻 | 必显 | 可选 | 不要 |
|------|------|------|------|
| 平时生产 | 资源、月相计时 | — | 满屏伤害数字 |
| 首只怪出现 | Toast + 威胁 ● | 边 vignette | 弹窗教程 |
| 战斗中 | 障碍/植物耐久 | 射程圈（选中时） | 实时 DPS 面板 |
| 幸存者被咬 | Toast + 食物数字 `-1` 飘字 | 屏震 50ms | 全屏红闪 |
| 月相结束 | 结算条（扣粮/水） | 下月相威胁预览 | 打断拖动 |

## 5. 颜色与图标语言（废土 UI）

对齐 `art-style-prompt.md`：低饱和、无霓虹。

| 语义 | 色 / 形 |
|------|---------|
| 入侵/敌人 | 铁锈红 `#8b4040` 描边 |
| 防御/障碍 | 灰褐 `#5a5550`，耐久条土黄 |
| 攻击/植物 | 暗绿 `#4a6a40`，射击闪暗黄 |
| 友方/幸存者 | 棕褐 `#8b7355` |
| 危险预警 | 琥珀 `#b8860b`，非纯红满屏 |

顶栏图标建议：**碗=食物、水滴=净水、齿轮=零件、骷髅=威胁**（简笔画，与卡牌同风格）。

## 6. 教学节奏（无长教程）

| 阶段 | 触发 | 教什么 |
|------|------|--------|
| 第 1 月相 | 固定场面只有灌木+幸存者 | 只学叠卡生产、点浆果收粮 |
| 第 2 月相 | 延迟刷 1 只犬 | Toast：「变异体逼近！用植物或武器。」 |
| 玩家首次叠种子到污壤 | 生长条 | Toast：「变异种子生长中…」 |
| 首次获得栅栏牌 | 抽到或奖励 | 高亮 slim 牌 3s +「竖牌放外围挡怪」 |
| 第 4 月相起 | 威胁指示器满格更常 | 月相条显示「下月：鼠↑」 |

**手册（可选）**：侧栏「生存手册」三页——入侵 / 防御 / 攻击，每页 1 张示意图 + 3 行字。

## 8. 与 Stacklands 玩家习惯对齐

| Stacklands 玩家预期 | 本作呈现 |
|---------------------|----------|
| 怪走向村民 | 怪走向幸存者卡 |
| 武器叠人 | 同样：武器在上 |
| 建筑挡一挡 | slim/wide 障碍挡线 |
| 月相末吃饭 | 月相末扣粮+水 |
| 不卖战斗数值 | 不卖 DPS，只卖「撑住」感受 |

---

## 9. 反面清单（避免）

- 不要战斗开始就弹「入侵/攻击/防御」三页说明。  
- 不要用 RPG 头顶满屏飘字。  
- 不要让射程圈常亮（杂乱）。  
- 不要让敌人和资源卡同色。  
- 手机上单指为主：信息靠 **看牌形 + 顶栏 + 偶尔 Toast**。

---

## 10. MVP 呈现（最小可做）

若只做一版：

1. 顶栏 **威胁 ●●○** + 敌人红描边  
2. 障碍/植物 **底耐久条**  
3. 植物开火 **小动画** + 击杀掉落旁蹦  
4. 月末 **涌动** 改月相条颜色 + 一行字  
5. 5 条固定 Toast 文案（逼近 / 损毁 / 收成 / 袭击 / 撑过月相）

即可让普通玩家理解三层，无需独立战斗 UI 场景。
