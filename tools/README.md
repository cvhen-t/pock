# 本地工具目录

## ComfyUI

官方仓库：[Comfy-Org/ComfyUI](https://github.com/Comfy-Org/ComfyUI)（原 comfyanonymous/ComfyUI）

网络可用时在项目根执行：

```powershell
git clone --depth 1 https://github.com/Comfy-Org/ComfyUI.git tools/ComfyUI
cd tools\ComfyUI
pip install -r requirements.txt
python main.py
```

或使用便携版 / `pip install comfy-cli` → `comfy install`（见 `.cursor/skills/comfyui/references/install-windows.md`）。

Agent 使用说明见：`.cursor/skills/comfyui/SKILL.md`
